# Documentación del Proyecto Inversión

Este directorio centraliza la documentación técnica, arquitectónica y operativa del proyecto.

## 📂 Subdirectorios

- **`arquitectura/`**: Diagramas, historias de usuario, modelo ERD y decisiones arquitectónicas.
- **`tecnica/`**: Especificaciones de APIs, seguridad, base de datos y guías de integración.
- **`metodologia/`**: Roadmap, plan de trabajo y estándares de desarrollo.
- **`pruebas/`**: Estrategia de pruebas unitarias, integración y e2e.
- **`usuarios/`**: Manuales y guías de usuario.
