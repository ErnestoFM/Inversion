# Paquetes Compartidos (`packages/`)

En este directorio se alojan las librerías internas y código compartido entre las distintas aplicaciones del monorepo.

## 📁 Estructura Sugerida

- `packages/shared-types`: Interfaces y tipos compartidos de TypeScript.
- `packages/database`: Cliente y modelos de base de datos (ej. Prisma, Drizzle u ORM).
- `packages/config`: Configuraciones compartidas (ESLint, Prettier, TypeScript).
